# Proyecto - Metodología

## Aprovechamiento y valorización de residuos agrícolas mediante la producción de bio-carbón (biochar) a partir de cáscara de papa de producción boyacense con aplicación agronómica y ambiental

## 1. Idea inicial

Queremos investigar cómo se puede producir biocarbón (biochar) mediante un proceso de pirólisis a partir de cáscara de papa generada en Boyacá.

La propuesta surge debido a que la cáscara de papa constituye un residuo agrícola que puede ser aprovechado y transformado en un material con potencial de aplicación agronómica y ambiental.

De esta manera, el proyecto busca explorar una alternativa de valorización de residuos agrícolas, promoviendo el aprovechamiento de recursos y la transformación de un residuo en un producto potencialmente útil.
