# Proyecto-metodologia
Aprovechamiento y valorización de residuos agrícolas mediante la producción de bio-carbón (biochar) a partir de cáscara de papa de producción boyacense con aplicación agronómica y ambiental.
Integrantes: CRISTHIAN CAMILO AVILA MEDINA, ARLEY FERNANDO PIÑA SIERRA
Idea inicial: Queremos saber cómo se puede producir biocarbón mediante pirólisis a partir de cáscara de papa
generada en Boyacá, porque esto permitiría aprovechar un residuo agrícola y transformarlo en un
material con potencial de aplicación ambiental, contribuyendo a la valorización de residuos y al
aprovechamiento de recursos.
Estado: Lección 1 — infraestructura configurada, idea sin refinar aún.
